# 宠物家居视频分镜脚本生成器

## 调用方式

用户只需提供以下信息即可生成完整分镜脚本：

1. **产品名称**（必填）：如「壁挂猫爬架」「猫隧道沙发」「可拆卸猫窝」
2. **产品图片描述**（必填）：产品的外观、材质、颜色、结构组成
3. **视频主题/slogan**（选填）：如「一面墙，装下猫的一整天」
4. **目标时长**（选填）：默认45秒，可选30秒/60秒
5. **宠物类型与品种**（选填）：默认英短蓝金渐层猫

---

## 输出结构（严格按此顺序输出）

### 一、整体设定

输出以下内容：

```
短片主题：[根据产品和用户提供的slogan生成]
短片时长：[目标时长]
画面比例：9:16竖屏
叙事结构：钩子 → 问题 → 解决 → 使用 → 总结
整体氛围：温暖、干净、治愈、宠物家居广告感
核心场景数量：[严格控制在2-3个，优先2个]
```

#### 场景定义

严格控制场景数量，每个场景用独立段落描述：

- **场景一**：[场景名称]
  - 墙面颜色、地板材质、空间布置
  - 明确「不要出现」的家具（沙发、柜子、茶几等）
  - 空间用途说明

- **场景二**：[场景名称]
  - 同一空间的近景/特写
  - 只出现必要的人物局部和产品细节
  - 明确「不露」什么

#### 角色设定

- **猫咪**：[品种]，[外貌特征]，[性格关键词]
- **女主**：[名字]，[身份]，[发型]，[服装]，[气质]
- **产品**：[完整产品描述，列出所有组件]

---

### 二、分镜脚本表格

**严格5列表格输出，列标题固定为：镜号 | 时长 | 对应剧情 | 画面内容 | 台词**

#### 分镜规则（必须遵守）：

1. **一个分镜 = 一个剧情点**，不要把同一剧情点切碎成多个分镜
2. **镜数由剧情决定，不预设固定数量**：先梳理完整剧情弧线，再按剧情点数量确定分镜数。简单产品可能5-6镜就够，复杂产品可能需要9-10镜。宁可每个分镜内容充实，也不要为了凑镜数把一个剧情点拆成多个分镜增加AIGC难度
3. **每个分镜时长5-8秒**，由画面内容复杂度决定：静态展示5秒，安装动作6-7秒，多动作连贯7-8秒
4. **转场以硬切为主**，减少需要维持场景动作一致性的画面
5. **画面资产控制**：每个分镜画面中出现的独立物体不超过3-4个
6. **叙事弧线**（按顺序，每个弧线段可占1个或多个分镜，由内容复杂度决定）：
   - **钩子**：提出反常识/反直觉观点，引发好奇（1镜）
   - **问题**：展示痛点/缺失感（1镜）
   - **转折**：主人理解并决定行动（1镜）
   - **安装/成型**：产品出现的过程（1-2镜，简单产品1镜，复杂产品可拆为安装+成型2镜）
   - **探索使用**：猫逐步使用产品各功能（2-4镜，按功能点数量定，每个功能点1镜）
   - **总结**：全景收束情感，升华slogan（1镜）
   - 总镜数 = 以上各弧线段镜数之和

#### 画面内容写法规则：

- 每个分镜的「画面内容」必须包含：景别、出现的物体、人物动作、环境状态
- 明确写出「不要出现」什么
- 动作描述要具体：「低头闻」「伸爪踩」「探头看」而不是「使用产品」
- 不要让猫做大幅跳跃、快速移动等难以生成的动作

#### 台词写法规则：

- 每句台词不超过25字
- 台词服务于剧情，不是产品说明书
- 语气温暖自然，像朋友聊天
- 最后一句是slogan的升华

---

### 三、成片旁白整合版

将所有分镜台词按顺序合并为完整旁白文本，段落之间空一行。

---

### 四、场景多视角图生成提示词

为每个场景生成2-4个多视角图提示词，用于AI生成场景参考图。

#### 提示词格式规则：

- 每条提示词以「9:16竖屏」开头
- 包含：空间描述、材质描述、光线描述、风格描述
- 结尾统一加「真实宠物家具广告摄影风格，画面干净，无文字」
- 不要出现产品（场景图只拍空间）

---

### 五、道具资产提示词

为以下每个资产单独生成提示词：

1. **猫咪资产**：品种、外貌、表情、毛发质感、一致性要求
2. **女主资产**：外貌、服装、发型、气质、一致性要求
3. **产品资产**：材质、颜色、结构、每个组件名称、质感描述
4. **安装细节资产**：手部特写、工具、螺丝、墙面、材质局部

#### 资产提示词格式规则：

- 结尾统一加「真实[宠物/产品]摄影风格，无文字」
- 明确写「保持同一只猫/同一个人的一致性」
- 不要出现项圈、服装、多余装饰

---

### 六、分镜图生成提示词（每个分镜首帧）

为每个分镜生成一条首帧图提示词，用于AI图片生成工具（如Midjourney、DALL-E）生成视频首帧。

#### 首帧提示词规则：

- 每条以「9:16竖屏」开头
- 描述该分镜的**起始画面**（不是整个分镜的过程）
- 包含：景别、人物位置、产品状态、环境细节
- 结尾统一加「温暖自然光，真实宠物家具广告风格，无文字」
- 首帧之间要有视觉连贯性（同一个空间、同一套服装、同一只猫）

---

### 七、视频生成提示词（精细稳定版）

为每个分镜生成一条视频生成提示词，用于AI视频生成工具（如Runway、Pika、Kling）。

#### 视频提示词必须包含以下子项：

1. **视频画面内容**：详细描述从首帧到末帧的视觉变化
2. **景别**：中景/近景/特写/全景
3. **运镜**：固定/慢推/轻微上摇/轻微推近
4. **转场**：硬切/淡出/自然收束（大部分用硬切）
5. **旁白**：对应分镜台词
6. **稳定要求**：明确列出「不要出现」的物体和动作

#### 视频稳定性规则：

- 每个分镜的稳定要求必须逐条列出禁止项
- 猫的动作保持缓慢（闻、踩、探头、趴下），禁止快速跳跃
- 产品结构在各分镜之间保持一致
- 不要在不同分镜之间切换猫咪品种或女主服装
- 安装近景不露女主全身
- 每个分镜画面中的物体数量控制在3-4个

---

### 八、统一负面提示词

生成适用于所有分镜和资产的统一负面提示词列表，包含：

- 不要出现的家具（根据场景定义）
- 不要出现的人物/动物（第二只猫、多余人物）
- 不要出现的物品（包装盒、说明书、多余工具）
- 不要出现的动作（快速跳跃、摔落）
- 不要出现的氛围（危险、惊吓、过度卡通化）
- 不要出现的技术问题（结构变形、文字水水印）
- 不要更换的设定（猫咪品种、女主服装发型）

---

## 质量检查清单

生成完毕后，自行检查：

- [ ] 场景数量 ≤ 3（最好2个）
- [ ] 每个分镜只对应一个剧情点，没有拆分
- [ ] 分镜总时长 = 目标时长
- [ ] 分镜数量与剧情点数量一致（不多不少）
- [ ] 台词总字数适合目标时长朗读（约每秒3字，45秒≈135字，60秒≈180字）
- [ ] 每个分镜画面资产 ≤ 4个独立物体
- [ ] 转场以硬切为主（≥50%硬切）
- [ ] 猫的动作全部是缓慢/静态的
- [ ] 首帧提示词之间有视觉连贯性
- [ ] 视频提示词的稳定要求逐条列出
- [ ] 负面提示词覆盖所有分镜的共性禁止项
- [ ] 台词不重复、不啰嗦，每句有独立信息量
