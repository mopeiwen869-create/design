设计思路

概述

本动画是一支基于 L4 级自动驾驶系统 HMI 交互设计的概念演示宣传片。核心目标是向观众（潜在用户、合作伙伴、企业）直观展示 L4 等级车辆在主要城市道路场景下的自动驾驶能力和数字人多模态交互体系。

叙事结构

动画采用「场景递进 + 交互与功能展示」的叙事逻辑，主要展示以下核心场景：

1 车辆起步，城市 ODD 内自主行驶
2 路口停车，乘客与车载 AI 多模态交互
3 路口行人感知与自动停车避让
4 变道避障提前预警，数字人拟人化动作提示
视觉风格

核心美学：单色调写实渲染 + 彩色主角对比——"灰白世界中的彩色主角"

AIGC 制作全过程

PHASE 1
前期策划与提示词设计
需求分析与分镜规划

明确视频核心卖点与技术亮点，调研车载 IP、语音助手、中控 SR 路况界面等，在博思白板归纳视频设计思路。利用 Claude Code 分析设计方案并编写分镜脚本，确定每个镜头的景别、运镜、时长、画面描述。

Prompt 工程

基于调研和故事脚本，在 ChatGPT 编写分镜图、数字人多视图、车辆外观三视图、图生视频、负面提示、一致性约束等 AI 生成所需的 Prompt。

PHASE 2
AI 素材生成
AI 图像生成

使用 Image2、nano banana 模型结合生成/负面/一致性 Prompt 创作图片素材，通过 Lovart 内置功能微调构图、视角等关系。

AI 视频片段生成

将图生视频 Prompt 输入 Hailuo 2.3、Kling 3.0、Veo 3.1 等视频生成模型，生成 5~10 秒视频片段。用 Wan 2.6 对不满意的视频进行多轮迭代调整，确保车辆运动轨迹、数字人动态、交通路况场景自然合理。

PHASE 3
后期合成与处理
视频片段拼接与剪辑

将各 AI 生成的视频片段导入剪映进行时间线排列，调整片段顺序、时长、转场，形成完整的叙事节奏。对不满意的片段重新生成并替换。

特效叠加与画面优化

对 AI 无法实现的复杂片段在剪映进行剪辑合成，例如重新生成部分车载 HMI 界面到车内镜头的屏幕区域，添加动效和镜头效果增强真实感。

字幕与音效

添加中文字幕、品牌 Logo、片头片尾信息。通过 Mureka 音频模型生成背景音和音效（最终版基于协调性考虑采用了已有音乐资产）。

技术难点与解决方案

多段视频风格一致性
解决方案：使用固定的 Prompt 模板 + 风格参考图锚定视觉风格，每段生成时携带参考图。
车辆运动轨迹不自然
解决方案：采用图生视频模式，以静态关键帧为起点，通过运镜和指向性 Prompt 指定运动方向。
长视频连贯性
解决方案：采用「关键帧锚定法」——先生成各镜头静态图，再逐镜头生成动态片段，最后剪辑拼接。

总结与复盘

本项目全程采用 AIGC 技术路线，以「场景递进 + 交互与功能展示」的叙事逻辑，围绕数字人的多模态交互体系和 L4 等级车辆自驾主要场景进行设计，通过 AI 图像生成、AI 视频生成、AI 音乐生成等工具链，完成了这部 L4 自动驾驶系统 HMI 设计演示动画的制作。

待优化方向

前期视觉基调、分镜及 Prompt 工程设计仍有欠缺。图片和视频模型未高度统一，导致最终成片的风格一致性和画面合理性以及行人动态等仍旧存在瑕疵，也是需要持续优化和进步的地方。
